# Rebuild3D v0.1.0

Rebuild3D 的首次 GitHub Release，将少图近似重建和真实照片贴图接入原生 macOS 应用的“生成模型”按钮。

用户添加同一物体的照片后点击一次，应用自动准备组件、选择路线、重建主体、生成照片纹理并保存展示。所有计算在本机执行，近似几何与照片颜色来源分别记录。

## 本次交付

- SwiftUI 应用、项目存储、自动生成调度与原生照片准备代码。
- 少图工作进程、通用几何融合、UV、照片纹理及来源记录。
- 取消、检查点恢复、有限自动后备、资源控制及旧结果保护。
- 完整组件和应用打包脚本、40 项 Swift 与 7 项 Python 测试。
- 带四张真实截图的 README、构建指南、使用说明与验收记录。

**本次提供源码和文档，未附可下载的完整 macOS 应用安装包。** GitHub 的 Source code 压缩包不包含 Python 运行环境、VGGT 权重、用户原图或验收模型。构建完整应用请参考[构建指南](../开发与构建.md)。

## 验证情况

两套独立的 7 张 HEIC 照片均在应用中零人工处理生成带贴图主体；33 张 JPEG、59 张 HEIC 的常规路线回归通过。新增 12 图对象在实现冻结后首次生成，混合格式、中文路径及文件身份也已验证。

实际应用取消、强制退出后的检查点恢复、真实 ENOSPC 和原图/旧模型保护通过；内存失败以故障注入验证有限重试。UV 展开期间真实睡眠 388 秒，唤醒后同一任务自动完成并保存。来源、保存重开、移位导出及禁止访问开发环境/网络的运行验收均已记录。

本机环境：Apple M5、16 GiB、macOS 26.4.1。完整过程见[执行与验收记录](../v3-一键生成执行与验收记录.md)。

## 限制

- 所有少图几何均为推测，比例不代表真实尺寸；仍有细部粗糙、细杆断裂、底座不完整和贴图接缝。
- 至少 3 张照片可以启动，不保证任意对象或任意少量照片都能成功。
- 当前验证 arm64 本地 ad-hoc 构建，未完成其他 Mac、Intel、公证或商业分发验证。
- VGGT 代码与权重许可分别适用；当前权重标注 CC BY-NC 4.0。仓库 Apache-2.0 许可不授予第三方权重商业使用权。

v0.1.0 对应内部 v3 方案的本机验收成果。历史实验标签 `v0.2.0-sparse-baseline` 保持不动；本次版本号以 `Config/Info.plist` 的 `0.1.0` 为准。
