# Rebuild3D v3 本地应用使用与交付说明

日期：2026-10-09。本机 P0 实施与验收已完成，M0–M5 全部通过；证据和质量局限见[执行与验收记录](v3-一键生成执行与验收记录.md)。

当前可运行应用位于 `build/v3-oneclick/delivery/Rebuild3D.app`（验收构建 09）。同目录有 A/B 两组用户照片、两组常规回归、新对象及混合输入的项目与导出。一键生成、质量、保存重开、来源、导出、独立离线运行和长任务恢复均已通过规定验收。

v0.1.0 的 Mac 二进制及配套附件已从 [GitHub Release](https://github.com/zihaomu/rebuild3d/releases/tag/v0.1.0) 撤下，当前只提供源码和文档。本地完整应用与分卷仍保留，体积明细及打包验证见 [Mac 安装包说明](macOS-安装说明.md)。候选包沿用已验收的算法与组件，版本号为 0.1.0。

## 使用方法

1. 打开包含生成组件的 `Rebuild3D.app`，点击“添加照片”。同一物体的一组照片放在同一个项目中。
2. 点击“生成模型”，等待应用准备组件、重建主体、铺设照片纹理并显示结果。无需安装 Python、开发工具或运行脚本。
3. 拖动旋转，滚轮缩放，Shift 拖动平移。近似模型可在“查看来源”中切换照片颜色、推测几何和颜色来源。
4. 点击 Save 选择正式项目位置；点击 Export USDZ 导出模型。生成成功会先自动保存到当前项目或可恢复草稿。

直接添加照片会自动建立草稿，无需先选项目目录。重新打开应用后，可从时钟菜单恢复草稿；已有正式项目用 Open 打开。文件夹导入只读取该层文件，子文件夹需要分别选择。重复文件、无法读取的图片和辅助文件有导入提示。

更换输入后，原模型仍可查看，但会显示“上次结果，当前照片尚未生成”。取消或失败不会把旧模型标为本次成功。此时导出对话框会说明导出的是上次结果。

## 等待、取消与继续

首次少图生成会在应用管理目录准备约 6.22 GB 的固定版本组件，之后每次校验完整性；组件缺失或损坏会从完整应用包修复。照片和计算均在本机，组件就绪后可以离线使用。

等待时间随照片与几何复杂度变化。本机验收中，新七图与旧七图的工作进程分别约 4 分钟及 12 分钟，额外十二图对象约 30 分钟，其中 UV 展开约 26 分钟。首次组件准备另计；测试期间还运行了其他验证，这些数值不是性能承诺。应用不会按固定 20 分钟总上限终止仍在计算的任务。

运行中点击“取消”，等待停止提示后可以关闭应用。重开相同项目再点击“生成模型”，少图任务会校验并复用已经完成的阶段；未完成的单个阶段重新计算。常规 Object Capture 的计算需重新开始。应用退出后不承诺后台继续运行。

本机已验证：少图任务在 UV 展开期间睡眠约 6 分 28 秒，唤醒后自动继续并保存，无需重新点击。睡眠时间会增加实际等待时间；这项验证不代表所有阶段、系统重启或其他机器均已覆盖。

同一台机器的重型生成会排队，避免多个应用窗口同时占用大量资源。不要同时在多个进程编辑同一个项目。资源错误的自动降配最多尝试两组配置；保存失败不会触发无意义的重复计算。磁盘空间不足时，保留照片和已有模型，释放空间后再试。

## 输入与效果边界

- 至少三张照片可以启动；三张不是质量保证。已经过核心验收的是用户提供的两套七图。
- 3–12 张自动使用近似路线；更多照片在能力允许时先使用常规路线，适用的计算失败会转入近似路线。需要缩减计算输入时，按照片内容选至多十二张，记录每张用途，全部原图仍保留。
- 近似路线的所有相机与几何都属于推测。橙色表示学习得到的深度形状，紫色表示轮廓补全；这不是实测精度或真实尺寸。
- 颜色来源中的彩色区域对应不同原照片，灰色表示外观填充。照片颜色覆盖不意味着相应几何准确。
- 少图结果可有面部、细杆、空腔、顶部及底座的粗糙、局部缺失和贴图接缝。自动结果不等于第二阶段手工修订的 r6。照片不足时不保证任意对象都能成功，也不会用无关模型替代失败结果。

当前本机验证环境为 Apple M5、16 GiB 内存、macOS 26.4.1。完整应用是 arm64 本地构建；尚未宣称 Intel、其他 Mac、商业发布或公证分发已验证。开发工具仅用于构建和验收，不是普通用户的运行前提。

## 项目和导出应如何保留

将整个 `.rebuild3d` 项目包一起保存或移动，其中包含原照片、输入身份、模型与来源记录。当前项目格式为 3，旧格式在读取后保留原有数据，并在成功保存时迁移。

近似模型导出包括：

- `名称.usdz`：可独立加载的模型及嵌入贴图。
- `名称.rebuild3d-result/`：照片身份、几何与颜色来源、来源模型，以及带纹理的 GLB 等附件。

分享近似结果时应同时保留来源附件，避免把推测模型误当成精确测量。附件目录已存在时请选择新名称，应用不会静默覆盖它。常规重建导出 USDZ，其材质和贴图包含在文件内。

验收成果保存在 `build/v3-oneclick/delivery/`。A 为 `data` 的旧七图，B 为 `data2` 的新七图；D 为另一个公开对象。恢复、混合输入及故障注入使用独立测试副本，不替代 A/B 核心项目。

## 组件与许可记录

在“高级选项 → 查看本地组件许可…”查看本次包的声明。应用包内保留 `GenerationRuntime/NOTICE.md`、固定版本组件清单及相应许可文件。VGGT 代码和权重许可分别记录；当前权重带有非商业使用约束，本地验收通过不代表已获得商业再分发许可。

本轮不需要用户接受新的在线服务条款或上传原照片。当前应用使用本地 ad-hoc 签名；正式签名、公证和商业分发属于后续交付范围。
